Q-music Android 0.4.16

本次安卓更新优化应用内更新说明的阅读体验，随 PC 0.4.16 一同正式发布。

### 更新弹窗

- 支持 Markdown 标题、列表、加粗、引用、代码和链接，更新内容不再直接显示原始标记。
- 排版跟随应用主题和字号，正文支持长按复制；隐藏 GitHub 发布流程附带的 HTML 注释。
- 网页链接打开失败时给出明确提示。

### 安装说明

- 安卓 versionCode 46；提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用 APK，大多数手机请选择 arm64-v8a。
- 沿用正式版应用标识与发布签名，可覆盖升级。独立 preview 测试版与正式版的数据相互独立。
- 旧版本此次升级前的更新提示仍使用旧版显示方式；安装本版后才生效。
- PC 版同时修复搜索源记忆、QQ 搜索分页、搜索历史重复及界面切换问题；这些 PC 布局调整不属于本次安卓改动。
