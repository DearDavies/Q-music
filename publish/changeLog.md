Q-music 0.4.12

本次正式版集中完善 QQ、网易云与酷狗账号体验，统一推荐切换，并优化账号管理界面。

### 音乐账号与登录

- 新增酷狗音乐 App 扫码登录，可读取并导入默认收藏、我喜欢、自建及收藏歌单。
- 修复 PC 的 QQ 音乐微信扫码在手机允许后仍停留“扫描成功”的问题，恢复官方授权回调；正确区分 QQ 与微信的音乐账号凭证。
- PC 的 QQ 音乐与网易云沿用官方登录窗口，支持调整大小和小屏幕适配；酷狗保留简洁扫码界面。
- 安卓同步接入酷狗扫码登录，并完善 QQ 微信授权入口与凭证识别。账号凭证仅在本机保存，直接请求对应平台官方接口。

### 个性化推荐与歌单

- PC、安卓首页均可切换 QQ、网易云、酷狗推荐，并记住选择；安卓账号页也可设置首页推荐来源。
- 新增酷狗账号每日推荐；网易云直接读取账号每日推荐；QQ 默认使用账号雷达，官方每日 30 首作为可选额外授权。
- QQ 官方每日 30 首入口整合到 QQ 账号管理中，减少分散设置；网易云与酷狗无需填写 QQ 的授权 Key。
- 账号管理提供歌单与收藏导入入口，保留平台推荐顺序；切换平台时防止旧请求覆盖当前内容。
- 推荐不可用时明确显示本地精选；退出或切换账号后不复用上一账号的推荐。
- 酷狗歌单完整取得后才写入本地，失败或取消保留原列表；再次导入同一来源歌单更新已有列表。

### 界面与交互

- PC 账号卡片增加“管理／收起”和方向箭头，再次点击即可收起，切换平台时自动折叠上一项。
- 调整卡片底色、按钮、间距与展开动画；登录、导入、退出放在展开区域，减少误触。
- 账号窗口保留滚动条和关闭入口，支持键盘操作与小窗口布局；更新三平台的清晰矢量图标。

### 安装与说明

- Windows x64、Arch Linux x64 和 Android 同步升级至 0.4.12；安卓 versionCode 42，提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用 APK。大多数手机请选择 arm64-v8a。
- 账号登录用于歌单和推荐，本次酷狗接入不包含会员播放能力；歌曲播放仍需可用音乐源。
- 已验证 PC 的 QQ 微信授权、酷狗登录及收藏读取、酷狗 30 首日推和账号卡片交互；安卓通过自动化回归与构建，扫码授权及实际体验仍需在手机上验证。

Q-music Android 0.4.11

本次正式版改善 Windows 与 Android 的更新检查和下载流程，重点处理 GitHub 连接不稳、下载停滞和重试体验。

### 更新线路

- 加入 ghfast.top、gh-proxy.com 两条公共镜像。检查版本和下载安装包均可使用备用地址，无需自行配置服务器。
- 下载前并行检测当前版本的发布文件，按响应时间选择可用线路；下载约 30 秒没有进展时自动停止该次请求并换线，失败后进行有限重试。
- 更新窗口和设置页显示当前线路、重试状态与进度；重复点击不会同时启动多个下载任务。
- GitHub API 可用时以已公开的正式 Release 为准；不可用时回退版本文件及镜像。PC 与安卓仍使用各自的更新通道，排除预发布。

### 下载与安装

- PC 保留 electron-updater 的 SHA-512 文件校验；公共镜像使用完整安装包下载。能够取得 GitHub 元数据摘要时，额外验证更新描述文件。
- 安卓新增 SHA-256 校验，同时检查 HTTP 状态与下载长度，避免把错误网页或不完整文件交给安装器。
- 安卓已完成且校验通过的安装包可复用；安装授权失败后可再次安装，无需重新下载。尚未实现安卓失败任务的断点续传，换线时不完整文件会重新下载。
- 预留 Cloudflare R2 公开镜像配置，本次默认使用公共镜像，不要求配置 Cloudflare 或 OneDrive。

### 安装包与验证

- Windows x64、Arch Linux x64 和 Android 同步升级至 0.4.11；安卓 versionCode 41，提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用 APK。
- 更新回归覆盖断网换线、错误响应、下载截断、校验失败、重复点击、缓存复用和平台版本隔离；此前已验证现有正式安装包可通过镜像完整下载并通过校验。
- 公共镜像可用性及速度取决于所在网络。从旧版升级到本版仍使用旧版更新器；本版安装完成后，后续更新才会使用新的自动选线流程。

Q-music Android 0.4.6

### 列表、搜索与云端曲库

- 统一歌单多选操作，修复全选状态、范围选择、隐藏栏拦截触摸，并优化长标题与窄屏按钮布局。
- 添加歌曲和新建歌单使用明确确认／取消；保存失败保留输入，避免失焦误建、重复保存及旧请求覆盖。
- 修复旧搜索结果回弹，完善返回键层级和设置分类定位。
- 云端曲库补齐配置折叠、未保存草稿保护、密钥显示、歌曲筛选、当前结果全选和操作反馈，上传后保留原列表。

### 播放与下载

- 播放队列显示暂停／继续状态，重新打开自动定位当前歌曲，并提供定位入口及操作失败反馈。
- 修复下载页已有任务不显示、重复排队和重试问题；明确区分移除记录与同时删除音乐文件，删除失败保留任务。
- 优化下载条目的长歌手名排版、进度显示及操作按钮。
- 定时设置增加 15／30／60／90 分钟快捷选择，严格校验 1–1440 整数分钟，修复等待播完当前歌曲时的状态更新。
- 修复进度拖动取消后的复位，改善弹窗和歌单详情操作反馈。

### 安装包

- 正式签名版本，版本号 0.4.6、versionCode 36；提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用 APK。
